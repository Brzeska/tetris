Simplified tetris clone programmed from scratch in one afternoon:D


Runs in any unix terminal

REQUIRES NUMPY: for osx, `pip install numpy`, for linux `apt install python3-numpy`

Arrow keys to run: 

up is rotate

lr is move piece

down is soft drop


Currently wall kicking is not supported and there is no 
"game over" condition yet. Also need to fix rendering bug


`python3 engine.py` to run :)
